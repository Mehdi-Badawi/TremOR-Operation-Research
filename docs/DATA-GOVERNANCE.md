# Data and governance

- Recordings stay on the phone unless the user chooses to share them.
- No account and no tracking.
- Users label their own data: material, location, and what the engineer later
  found.
- Users decide whether a recording joins the open dataset. Only consented
  recordings are published.
- Organizations can keep a private model tuned on their own data. The shared
  base model learns only from data people choose to contribute.
- Data collection with volunteers goes through university human-subjects
  review.
